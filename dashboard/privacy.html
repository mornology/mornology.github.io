Privacy policy

Personal Dashboard is a private app used only by its owner. It is not offered to anyone else.

  • What it reads: only the owner's own data, with read-only permissions (for example weight, sleep and resting heart rate).
  • Where data goes: to the owner's own home server, where it is shown on a screen at home. It is not sold, shared, or sent to any third party, and is not used for advertising.
  • Storage: sign-in tokens and recent readings are kept on the owner's home server only. Revoking the app's access in the Google account removes its access immediately.
  • Google API Services: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
